DIAPOSITIVA 5 DE 11 · ARQUITECTURA CLOUD Habla Álvaro (02:00 - 03:00)
Una API central coordina tres universos tecnológicos
Qué tienes que decir (Tu primer bloque fuerte):
"Para soportar esta operación en terreno, diseñamos una arquitectura en tres capas desacopladas que consumen una misma API central:

1. Los dos clientes: En el celular, una app en Android nativo con Jetpack Compose para los voluntarios; en el computador, una consola web en React 19 desplegada en Vercel para los coordinadores.

2. La nube y seguridad: Ambos clientes entran por AWS API Gateway con cifrado HTTPS. La autenticación federada la gestiona AWS Cognito, emitiendo tokens JWT firmados con RS256.

3. Backend y persistencia: Un microservicio en Spring Boot 3 con Java 21 ejecutándose en una máquina virtual AWS EC2 con Ubuntu, conectado a una base de datos relacional PostgreSQL 16.

Lo clave es que si un alumno acredita desde Android o un docente registra desde la web, ambos consumen el mismo backend y validan el mismo token JWT."
Tip en la micro: Grábate la cadena: "React y Android -> API Gateway -> Cognito RS256 -> Spring Boot en EC2 -> PostgreSQL 16". Si dices esa cadena fluida, el profesor sabe de inmediato que dominas la arquitectura.

Respuestas Técnicas de Álvaro (Para el 7.0)

1. "¿Por qué usaron PostgreSQL y no DynamoDB o MongoDB en AWS?"
"Porque nuestro modelo de datos es estrictamente relacional: los talleres, cupos, asistencias y usuarios tienen relaciones de llaves foráneas e integridad referencial estricta. Una base NoSQL nos obligaría a desnormalizar datos y aumentaría el riesgo de inconsistencia al calcular el quórum en vivo."
2. "¿Por qué delegaron la autenticación en AWS Cognito?"
"Porque las mejores prácticas de la industria exigen no almacenar contraseñas en texto plano ni en hashes propios en la base de datos de la aplicación. Cognito maneja estándares RFC, recuperación de cuentas segura y emite tokens JWT firmados con RS256 que nuestro backend valida con la clave pública de AWS."
3. "¿Cómo generaron el sonido de confirmación al escanear?"
"Usamos la Web Audio API nativa del navegador. En lugar de cargar archivos MP3 pesados que consumen datos, creamos un oscilador sinusoidal por software con una rampa exponencial de 880 Hz a 1760 Hz en 120 milisegundos. Es 100% nativo, pesa cero kilobytes y suena de forma instantánea."
4. "¿Qué garantizan las 25 pruebas unitarias con Vitest?"
"Garantizan que el cliente HTTP maneje errores de red, que los guards de autenticación bloqueen rutas no autorizadas, que el parseo de tokens JWT sea correcto y que los componentes de React rendericen sin excepciones en menos de 2 segundos."
