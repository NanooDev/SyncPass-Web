1. Introducción, Qué Problema Resolvemos y Cómo Usamos la IA

Diapositivas 1, 2 y 3 de la presentación.

Qué decir frente al profesor:
"Buenos días profesor. Hoy junto a Álvaro presentamos SyncPass, nuestra solución de asistencia y gestión para los talleres comunitarios de Vinculación con el Medio de Duoc UC.

El problema real que resolvemos es que en las juntas de vecinos la asistencia se sigue anotando a mano en hojas de papel. Eso genera desorden, se pierden datos y los coordinadores no tienen idea del quórum real hasta días después.

2. Arquitectura de los 3 Universos

Diapositiva 4 de la presentación.

Qué decir frente al profesor:
"El proyecto está dividido en tres universos conectados pero independientes:

1. Las aplicaciones cliente: Por un lado tenemos la app móvil en Android nativo con Jetpack Compose y MVVM, y por otro la aplicación web en React 19 con TypeScript que tenemos desplegada en Vercel.

2. La nube de AWS: Ambos clientes consumen exactamente la misma API a través de AWS API Gateway con HTTPS. La seguridad y los usuarios los maneja AWS Cognito, que emite tokens JWT.

3. El backend y la base de datos: Tenemos un servidor en Spring Boot 3 con Java 21 corriendo en una máquina virtual AWS EC2 con Ubuntu, conectado a una base de datos PostgreSQL.

Lo importante aquí es que si entras desde el teléfono o desde la web, entras con la misma cuenta y el JWT se valida en el mismo backend central."

Palabras técnicas clave que deben sonar:

  • Jetpack Compose y MVVM en Android.
  • React 19 + TypeScript en Vercel en Web.
  • AWS EC2 + API Gateway HTTPS + Cognito con JWT en Backend.
  • Misma API compartida para ambas plataformas.

3. Demostración en Vivo: Universo Mobile (Android)

Diapositiva 5. Mostrar la app en el celular o Android Studio.

Qué decir frente al profesor:
"En la aplicación Android usamos Jetpack Compose para diseñar la interfaz y la arquitectura MVVM con Retrofit y Corrutinas para las llamadas de red.

Cuando el usuario inicia sesión, la app toma el token JWT, lo lee con nuestro componente JwtDecoder y lo redirige de inmediato a la pantalla según su rol (Docente, Estudiante o Administrador) sin pedir confirmaciones intermedias.

Cumpliendo con la rúbrica, tenemos dos mantenedores en el celular:
• Mantenedor 1 (Talleres y Quórum): Muestra la lista de talleres territoriales con su barra de quórum en vivo y permite generar el código QR para que la gente marque asistencia.
• Mantenedor 2 (Administrador): Permite ver el estado de los operadores territoriales y enviar alertas push directo al teléfono."

Palabras técnicas clave que deben sonar:

  • Jetpack Compose (interfaz moderna de Android).
  • MVVM, Retrofit y Corrutinas (arquitectura y llamadas a la API).
  • Redirección reactiva por JWT (cada rol ve su pantalla directa).
  • 2 Mantenedores en móvil: Talleres/Quórum y Administración/Alertas.

Preguntas Clave del Profesor

Respuestas directas y fáciles de memorizar para responder con seguridad.

Responde Mariano Pregunta Típica 1

"¿Qué dato o función agregarías en la app móvil que no tenga sentido en la web?"

"Profesor, en la app móvil agregaríamos la ubicación por GPS al escanear el QR y almacenamiento en caché offline con Room SQLite.

En la web no tiene sentido porque los coordinadores trabajan desde un computador en una oficina fija con wifi. En cambio, en el celular estás en terreno, en una junta de vecinos donde la señal móvil puede fallar y donde necesitas certificar con GPS que la persona realmente estuvo en el lugar físico del taller."
Responde Álvaro Pregunta Típica 2

"¿Por qué usaron AWS Cognito en lugar de hacer un login manual tradicional?"

"Porque en el desarrollo profesional de hoy no es una buena práctica guardar contraseñas en tu propia base de datos por el alto riesgo de filtraciones.

Al usar AWS Cognito, delegamos la seguridad en un proveedor especializado que maneja los estándares de la industria, nos entrega tokens JWT firmados y gestiona la recuperación de contraseñas de forma automática."
Responde Mariano Pregunta Típica 3

"¿En qué se diferencia su propuesta del resto de los proyectos?"

"En vez de hacer un carrito de compras o una tienda genérica, nosotros nos enfocamos en una necesidad real de Duoc UC: la Vinculación con el Medio.

SyncPass resuelve la acreditación comunitaria en terreno con códigos QR rápidos y control de quórum en tiempo real, lo que permite a la institución medir el impacto social de sus talleres con datos reales y sin planillas de papel."
Responde Álvaro Pregunta Típica 4

"¿Por qué PostgreSQL y no una base NoSQL como DynamoDB en AWS?"

"Porque nuestros datos son estrictamente relacionales: los talleres, los cupos, los usuarios y las asistencias se conectan con llaves foráneas y reglas de integridad. Usar DynamoDB nos obligaría a desnormalizar datos sin necesidad. Además, PostgreSQL corriendo en nuestra máquina EC2 nos da rendimiento nativo a costo cero para el laboratorio."

Glosario: Para Hablar Técnico Sin Enredarse

Qué significa cada palabra y cómo explicarla en una sola frase sencilla.

Jetpack Compose
La librería moderna de Google para hacer pantallas en Android usando código Kotlin directo, sin archivos XML antiguos.
MVVM (Modelo - Vista - VistaModelo)
El patrón de diseño que separa lo visual (la vista) de la lógica de datos (el ViewModel) para que el código sea limpio y testeable.
Retrofit y Corrutinas
Retrofit hace las peticiones a la API web y las Corrutinas hacen que la aplicación no se quede pegada mientras espera la respuesta.
Room / SQLite
La base de datos interna que vive dentro del teléfono celular para guardar datos cuando no hay conexión a internet.
JWT (JSON Web Token)
Un carnet digital seguro y firmado que viaja en cada petición para comprobar quién eres y qué rol tienes (Admin, Docente, Alumno).
AWS EC2
Un servidor virtual en la nube de Amazon donde dejamos corriendo nuestro backend de Spring Boot con Java.
AWS API Gateway
La puerta de entrada segura con HTTPS que recibe los llamados de la app y la web y los redirige hacia el servidor.
AWS Cognito
El servicio de Amazon que administra las cuentas de usuario, las contraseñas y el inicio de sesión seguro.
CRUD
Las cuatro funciones esenciales de cualquier mantenedor: Crear, Listar (Read), Modificar (Update) y Borrar (Delete).
Vitest
El framework con el que creamos las 25 pruebas automáticas para asegurar que ningún botón o llamada a la API falle.
