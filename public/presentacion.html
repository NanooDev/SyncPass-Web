SyncPass

Plataforma Full Stack de Gestión de Talleres Comunitarios y Asistencia en Tiempo Real con Roles en la Nube de AWS.

1

Universo Mobile

Android nativo en Kotlin con Jetpack Compose y MVVM. Redirección automática según el rol al leer el token JWT.

2

Universo Web

Single Page Application en React 19 + TypeScript en Vercel con mantenedores CRUD interactivos y 25 pruebas unitarias.

3

Universo Cloud AWS

Backend en Spring Boot 3 en AWS EC2 con API Gateway HTTPS y login seguro con AWS Cognito.

Problema y Solución Orador: Mariano

El Problema Real y la Solución SyncPass

Digitalización de la asistencia comunitaria con códigos QR rápidos y control de quórum en tiempo real.

✕

El Problema en Terreno

  • Registro manual en hojas de papel con riesgo de pérdida de datos.
  • Incertidumbre sobre cuántos alumnos y vecinos asistieron al taller.
  • Cuatro roles con necesidades distintas: docentes, alumnos, vecinos y admin.
  • Señal 4G inestable en juntas de vecinos y sedes comunitarias.
✓

La Solución SyncPass

  • Código QR instantáneo: Acreditación en menos de 2 segundos.
  • Roles claros: Cada usuario ve solo lo que le corresponde por JWT.
  • Plataforma Web: Panel de control para coordinadores y directores.
  • Preparado para offline: Diseñado para funcionar sin internet con caché local.
Metodología de Desarrollo Orador: Mariano

Arquitectura del Sistema Orador: Álvaro

Arquitectura de los 3 Universos

Tres capas conectadas: App móvil en Android, Web en React y Backend en Spring Boot con AWS.

1. Clientes Frontend

  • Android Nativo: Jetpack Compose, MVVM, Retrofit y Corrutinas.
  • Web SPA: React 19, TypeScript, Vite y CSS Modules.
  • Navegación por Roles: Redirección directa según el token JWT.

2. Capa Cloud de AWS

  • AWS API Gateway: Punto de entrada único HTTPS con CORS.
  • AWS Cognito: Directorio seguro de usuarios y emisión de JWT.
  • AWS EC2: Servidor Ubuntu corriendo el microservicio Spring Boot.

3. Backend y Datos

  • Spring Boot 3: Java 21 con Spring Security Resource Server.
  • Spring Data JPA: Repositorios relacionales con Hibernate.
  • PostgreSQL: Base de datos relacional para talleres y usuarios.

Infraestructura y Nube Orador: Álvaro

Backend y Servicios Cloud de AWS

Servicios en la nube de AWS protegidos con HTTPS y autenticación profesional con AWS Cognito.

EC2

AWS EC2 Ubuntu

  • Servicio systemd syncpass-api con reinicio automático.
  • Swapfile de 2 GB para soportar compilaciones fluidas.
  • Spring Boot 3 con Spring Security y validación de JWT.
API

AWS API Gateway

  • Punto de entrada seguro HTTPS hacia el backend.
  • Protección perimetral y desacoplamiento de la IP del servidor.
  • CORS configurado para recibir llamadas desde Vercel y Android.
IDP

AWS Cognito

  • User Pool con verificación segura de cuentas.
  • Emisión de tokens JWT firmados digitalmente.
  • Cero riesgo de filtración de contraseñas locales.
