SyncPass

Ecosistema Full Stack de Acreditación Territorial y Gestión de Talleres Comunitarios con Arquitectura Multi-Rol en la Nube de AWS.

1

Universo Mobile

Android nativo en Kotlin con Jetpack Compose y arquitectura MVVM. Redirección reactiva por roles mediante decodificación de JWT.

2

Universo Web

Single Page Application en React 19 + TypeScript + Vite, desplegada en Vercel con mantenedores CRUD interactivos y 25 pruebas unitarias.

3

Universo Cloud AWS

Backend Spring Boot 3 en AWS EC2 Ubuntu, enrutado por AWS API Gateway HTTPS y securizado con identidades federadas en AWS Cognito.

Contexto y Propuesta de Valor Orador: Mariano

El Problema Territorial y la Solución SyncPass

Modernización de la gobernanza comunitaria mediante trazabilidad criptográfica y supervisión de quórum en terreno en tiempo real.

✕

El Desafío Territorial

  • Registro manual en planillas físicas con riesgo de inconsistencias y pérdida de información.
  • Incertidumbre de coordinadores docentes sobre asistencia y quórum efectivo de talleres.
  • Cuatro perfiles con necesidades operativas distintas: docentes, voluntarios, vecinos y administradores.
  • Conexión móvil inestable en sedes comunitarias y juntas de vecinos.
✓

La Solución SyncPass

  • Generación y escaneo instantáneo de credenciales QR por taller y beneficiario.
  • Segregación estricta de privilegios por roles (RBAC) resuelta a nivel de token JWT.
  • Consola web institucional para coordinadores y dirección de carrera.
  • Arquitectura desacoplada lista para sincronización offline-first y base central.

Topología del Sistema Orador: Álvaro

Arquitectura de los 3 Universos

Desacoplamiento total entre capas de presentación móvil y web, compuerta API unificada y servicios de identidad en la nube.

1. Clientes Frontend

  • Android Nativo: Jetpack Compose, MVVM, Retrofit y Corrutinas de Kotlin.
  • Web SPA: React 19, TypeScript, Vite, CSS Modules y Wouter Routing.
  • Decodificación Local: Decodificación de claims JWT para navegación condicional.

2. Capa Cloud & Gateway

  • AWS API Gateway: Endpoint público HTTPS (`5xvspck6jb`) con enrutamiento proxy.
  • AWS Cognito User Pool: Directorio institucional, emisión de JWT firmados con RS256.
  • AWS EC2: Servidor Ubuntu con systemd `syncpass-api` y Nginx reverse proxy.

3. Capa de Datos & Dominio

  • Spring Security: Resource Server con validación criptográfica JWKS pública.
  • Spring Data JPA: Repositorios relacionales con Hibernate y DTOs seguros.
  • PostgreSQL 16: Base de datos relacional para usuarios, roles y auditoría.

Universo Backend y Cloud AWS

Arquitectura de servicios protegida con estándares de la industria (OAuth 2.0 / OpenID Connect).

EC2

AWS EC2 Ubuntu

  • Servicio systemd `syncpass-api` con reinicio automático.
  • Swapfile de 2 GB configurado para soportar compilaciones eficientes.
  • Spring Boot 3 con Spring Security y Resource Server JWT.
API

AWS API Gateway

  • Punto de entrada HTTPS (`5xvspck6jb.execute-api.us-east-1.amazonaws.com`).
  • Protección perimetral y desacoplamiento de la IP pública del servidor.
  • CORS configurado para permitir consumos desde Vercel y Android.
IDP

AWS Cognito User Pool

  • Pool `us-east-1_RlB8Ft9Z2` con validación de teléfono y correo.
  • Firma digital RS256 con claves JWKS públicas verificables.
  • Reducción a cero del riesgo de filtración de contraseñas locales.
